# 隨手筆記

全家人的小怪獸筆記本。網頁放在 GitHub Pages，筆記存在 Google 雲端硬碟「隨手筆記」資料夾。

- `index.html` `app.js` `style.css` `monsters.js`：筆記本網頁
- `config.js`：Google Apps Script 網頁應用程式的網址
- `apps-script/Code.gs`：貼到 Google Apps Script 的後端程式
- `icons/`：藍藍熊主畫面圖示（Patty 原稿）

資料檔 `suishou-notes.json` 會在每次變動後更新到 Google 雲端硬碟資料夾，給其他工具讀取。
